# Nguồn AI hữu ích đáng follow

Danh sách nguồn chất lượng để theo dõi và lấy tài liệu, nhóm theo chủ đề. Gợi ý cho người dùng theo tag họ hay lưu. Khuyến khích thử 1-2 nguồn rồi mới mở rộng.

## Coding agent & Claude Code
- **Claude Code docs** — https://docs.claude.com/en/docs/claude-code — tài liệu chính thức: skills, hooks, MCP, subagents.
- **Anthropic Engineering blog** — https://www.anthropic.com/engineering — bài sâu về agent design, context, eval.
- **addyosmani/agent-skills** (GitHub) — bộ skill đóng gói kỷ luật của senior engineer cho coding agent.
- **Awesome Claude / Awesome LLM tools** (GitHub, search "awesome claude code") — tổng hợp tool & skill cộng đồng.

## Agent design & patterns
- **Anthropic "Building effective agents"** — https://www.anthropic.com/research — pattern thiết kế agent (chaining, routing, orchestrator).
- **LangChain / LlamaIndex blogs** — pattern RAG, tool use, memory (đọc có chọn lọc, nhiều thứ thiên về sản phẩm của họ).

## Prompting & LLM fundamentals
- **Anthropic prompt engineering docs** — https://docs.claude.com/en/docs/build-with-claude/prompt-engineering
- **Prompt engineering guide** — https://www.promptingguide.ai

## Tin tức & xu hướng (lọc nhiễu cao)
- **GitHub Trending** — https://github.com/trending — lọc theo ngày/tuần, ngôn ngữ; nơi repo như agent-skills nổi lên.
- **Hacker News** — https://news.ycombinator.com — thảo luận kỹ thuật chất lượng (đọc comment hơn tiêu đề).
- **Simon Willison's blog** — https://simonwillison.net — ghi chú thực dụng về LLM/tooling, cập nhật dày.

## MCP & tooling
- **Model Context Protocol docs** — https://modelcontextprotocol.io
- **MCP servers registry** (GitHub `modelcontextprotocol/servers`) — server mẫu để tích hợp.

## Cách dùng danh sách này
- Khi người dùng hay lưu tag `coding-agent` / `claude-code` → ưu tiên nhóm đầu.
- Khi lưu tag `RAG` / `agent-design` → nhóm Agent design.
- Đề xuất tối đa 3 nguồn mỗi lần để tránh quá tải.
- Bổ sung nguồn mới vào đây khi phát hiện nguồn tốt trong lúc curate.
