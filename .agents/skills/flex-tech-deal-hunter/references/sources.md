# Sources and Sale Calendar

Starting points, not a closed list. Treat every entry as a lead and verify at the provider's own page. Update this file when a source dies or a new one proves reliable.

## Official programs (highest trust)

- Cloud free tiers and credits: AWS Free Tier, Google Cloud Free Program, Azure Free Account, Oracle Cloud Always Free, Vultr Free Tier (https://www.vultr.com/free-tier-program/), DigitalOcean, Linode/Akamai, Hetzner promos.
- Edge/platform free plans: Cloudflare, Vercel, Netlify, Fly.io, Render, Railway, Supabase, Neon.
- Education/OSS/startup: GitHub Student Developer Pack, JetBrains (student/OSS), AWS Activate, Google for Startups, Microsoft for Startups.
- AI API credits: provider startup/research programs and promo credits on each provider's own console.

## Seasonal sales (providers and registrars)

- Global: Cloudflare Registrar, Namecheap, Porkbun, Hostinger, Contabo, Hetzner, OVH, RackNerd, BuyVM.
- Vietnam: BKNS, Mat Bao, Nhan Hoa, PA Vietnam, AZDIGI, Viettel IDC / VNPT / FPT Cloud promos.

## Community leads (verify before trusting)

- LowEndTalk, Reddit (r/VPS, r/selfhosted, r/homelab), Hacker News, Tinhte, Voz.
