# Data model: Chuẩn hóa requirements template

Không có persisted data hoặc schema. Artifact Markdown có các khái niệm sau:

| Khái niệm | Thuộc tính cần có |
|-----------|-------------------|
| Requirements checklist | ID, feature link, lần/người/trạng thái review, kết quả và bước tiếp theo |
| Checklist item | `CHK###`, severity, status, câu hỏi chất lượng, tham chiếu hoặc marker gap |
| Phát hiện fail | Phát hiện, ảnh hưởng, đề xuất, tham chiếu, owner và hạn xử lý |
| Ngoại lệ | Item, lý do, rủi ro, người phê duyệt và hạn xem lại |
