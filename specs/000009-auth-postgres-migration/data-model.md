## 1. Danh sách thực thể & Bảng Database

Bảng PostgreSQL thuộc database `aspnetidentity`, tuân theo quy ước thiết kế trong `flex-database/docs/convention.md`.

### 1. Bảng `USERS` (Tài khoản người dùng)
- **ID**: `UUID` (Primary Key)
- **USER_NAME**: `VARCHAR(256)`
- **NORMALIZED_USER_NAME**: `VARCHAR(256)` (NOT NULL, UNIQUE Index: `UX_USERS_NORMALIZED_USER_NAME`)
- **EMAIL**: `VARCHAR(256)`
- **NORMALIZED_EMAIL**: `VARCHAR(256)` (Index: `IX_USERS_NORMALIZED_EMAIL`)
- **EMAIL_CONFIRMED**: `BOOLEAN` (NOT NULL, Default: `false`)
- **PASSWORD_HASH**: `TEXT`
- **SECURITY_STAMP**: `TEXT`
- **CONCURRENCY_STAMP**: `TEXT`
- **PHONE_NUMBER**: `VARCHAR(50)`
- **PHONE_NUMBER_CONFIRMED**: `BOOLEAN` (NOT NULL, Default: `false`)
- **TWO_FACTOR_ENABLED**: `BOOLEAN` (NOT NULL, Default: `false`)
- **LOCKOUT_END**: `TIMESTAMPTZ`
- **LOCKOUT_ENABLED**: `BOOLEAN` (NOT NULL, Default: `false`)
- **ACCESS_FAILED_COUNT**: `INT` (NOT NULL, Default: `0`)
- **FULL_NAME**: `VARCHAR(250)`

### 2. Bảng `ROLES` (Vai trò)
- **ID**: `UUID` (Primary Key)
- **NAME**: `VARCHAR(256)`
- **NORMALIZED_NAME**: `VARCHAR(256)` (NOT NULL, UNIQUE Index: `UX_ROLES_NORMALIZED_NAME`)
- **CONCURRENCY_STAMP**: `TEXT`
- **DESCRIPTION**: `VARCHAR(500)`

### 3. Bảng `USER_ROLES` (Quan hệ Người dùng - Vai trò)
- **USER_ID**: `UUID` (Primary Key component)
- **ROLE_ID**: `UUID` (Primary Key component)
- **Primary Key**: (`USER_ID`, `ROLE_ID`)

### 4. Bảng `ROLE_CLAIMS`
- **ID**: `INT GENERATED BY DEFAULT AS IDENTITY` (Primary Key)
- **ROLE_ID**: `UUID` (NOT NULL)
- **CLAIM_TYPE**: `VARCHAR(256)`
- **CLAIM_VALUE**: `VARCHAR(500)`

### 5. Bảng `USER_CLAIMS`
- **ID**: `INT GENERATED BY DEFAULT AS IDENTITY` (Primary Key)
- **USER_ID**: `UUID` (NOT NULL)
- **CLAIM_TYPE**: `VARCHAR(256)`
- **CLAIM_VALUE**: `VARCHAR(500)`

### 6. Bảng `USER_LOGINS`
- **LOGIN_PROVIDER**: `VARCHAR(128)` (Primary Key component)
- **PROVIDER_KEY**: `VARCHAR(128)` (Primary Key component)
- **PROVIDER_DISPLAY_NAME**: `VARCHAR(256)`
- **USER_ID**: `UUID` (NOT NULL)
- **Primary Key**: (`LOGIN_PROVIDER`, `PROVIDER_KEY`)

### 7. Bảng `USER_TOKENS`
- **USER_ID**: `UUID` (Primary Key component)
- **LOGIN_PROVIDER**: `VARCHAR(128)` (Primary Key component)
- **NAME**: `VARCHAR(128)` (Primary Key component)
- **VALUE**: `TEXT`
- **Primary Key**: (`USER_ID`, `LOGIN_PROVIDER`, `NAME`)

### 8. Bảng `PERMISSIONS` (Quyền hệ thống)
- **ID**: `UUID` (Primary Key)
- **CODE**: `VARCHAR(100)` (NOT NULL, UNIQUE Index: `UX_PERMISSIONS_CODE`)
- **NAME**: `VARCHAR(200)` (NOT NULL)
- **CATEGORY**: `VARCHAR(100)`
- **DESCRIPTION**: `VARCHAR(500)`

### 9. Bảng `LOGIN_HISTORIES` (Lịch sử đăng nhập)
- **ID**: `UUID` (Primary Key)
- **USER_ID**: `UUID` (NOT NULL, Index: `IX_LoginHistories_UserId`)
- **USER_NAME**: `VARCHAR(256)` (NOT NULL)
- **LOGIN_TYPE**: `VARCHAR(50)` (NOT NULL)
- **IP_ADDRESS**: `VARCHAR(50)`
- **RESULT**: `VARCHAR(1)` (NOT NULL)
- **FAILURE_REASON**: `VARCHAR(500)`
- **OCCURRED_ON**: `TIMESTAMPTZ` (NOT NULL, Index: `IX_LoginHistories_OccurredOn`)
- **Composite Index**: (`USER_ID`, `OCCURRED_ON`) -> `IX_LoginHistories_UserId_OccurredOn`

### 10. Bảng `OUTBOX_MESSAGES` (Transactional Outbox)
- **ID**: `UUID` (Primary Key)
- **EVENT_TYPE**: `VARCHAR(200)` (NOT NULL)
- **PAYLOAD**: `TEXT` (NOT NULL)
- **EXCHANGE**: `VARCHAR(200)` (NOT NULL)
- **ROUTING_KEY**: `VARCHAR(200)` (NOT NULL)
- **OCCURRED_ON**: `TIMESTAMPTZ` (NOT NULL)
- **STATUS**: `VARCHAR(10)` (NOT NULL, Default: `'Pending'`)
- **RETRY_COUNT**: `INT` (NOT NULL, Default: `0`)
- **ERROR_MESSAGE**: `VARCHAR(2000)`
- **PROCESSED_ON**: `TIMESTAMPTZ`
- **Index**: (`STATUS`, `OCCURRED_ON`) -> `IX_OUTBOX_MESSAGES_STATUS_OCCURRED_ON`

### 11. Bảng `INBOX_MESSAGES` (Transactional Inbox & Deduplication)
- **ID**: `UUID` (Primary Key)
- **MESSAGE_ID**: `UUID` (NOT NULL)
- **SOURCE**: `VARCHAR(64)` (NOT NULL)
- **EVENT_TYPE**: `VARCHAR(128)` (NOT NULL)
- **HANDLER_NAME**: `VARCHAR(128)` (NOT NULL)
- **BUSINESS_KEY**: `VARCHAR(128)` (Index: `IX_INBOX_MESSAGES_BUSINESS_KEY`)
- **PAYLOAD**: `TEXT` (NOT NULL)
- **FIRST_SEEN_AT**: `TIMESTAMPTZ` (NOT NULL)
- **PROCESSED_AT**: `TIMESTAMPTZ` (NOT NULL, Index: `IX_INBOX_MESSAGES_PROCESSED_AT`)
- **STATUS**: `VARCHAR(10)` (NOT NULL)
- **RETRY_COUNT**: `INT` (NOT NULL, Default: `0`)
- **ERROR_MESSAGE**: `VARCHAR(2000)`
- **UNIQUE Index**: (`MESSAGE_ID`, `HANDLER_NAME`) -> `UQ_INBOX_DEDUP`

## 2. Quy tắc chuyển đổi kiểu dữ liệu Oracle -> PostgreSQL

| Tên khái niệm | Oracle DB (Cũ) | PostgreSQL DB (Mới) | Ghi chú EF Core |
|---------------|----------------|---------------------|-----------------|
| Boolean | `CHAR(1)` ('1'/'0') | `BOOLEAN` | Xóa `BoolToCharConverter`, map trực tiếp boolean |
| Chuỗi văn bản dài | `CLOB` | `TEXT` | Thay `.HasColumnType("CLOB")` thành `.HasColumnType("text")` hoặc bỏ `HasColumnType` |
| Thời gian | `TIMESTAMP(6)` / `DATE` | `TIMESTAMPTZ` / `TIMESTAMP WITH TIME ZONE` | PostgreSQL lưu UTC chuẩn |
| Chuỗi có dấu | `NVARCHAR2` | `VARCHAR` / `TEXT` | PostgreSQL mặc định dùng UTF-8 |
